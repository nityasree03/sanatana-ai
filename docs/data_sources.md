# Data sources and licensing

No scripture, artwork or audio has been added yet (Phase 0).

## Rules

- "Free to read" does not mean "free to reuse". Every text, translation, illustration and
  recording needs a confirmed license or public-domain status before it is added.
- Each passage records: scripture, section, chapter/verse, original text, romanization, translation,
  translator, edition, source URL, license, language, ingestion date and verification status
  (enforced by `scripture-pipeline/sanatana_pipeline/provenance.py`).
- If something cannot be legally included or verified, the site shows "source unavailable".
