# Data sources and licensing

Every scripture passage on the site comes from the sources below (dataset version 1.0.0, 1341
passages). The pipeline that downloads, cleans and checks them is in `scripture-pipeline/`; each
download's SHA-256 is recorded in `scripture-pipeline/raw_manifest.json`.

## Rules

- "Free to read" does not mean "free to reuse". Every text, translation, illustration and
  recording needs a confirmed license or public-domain status before it is added.
- Each passage records: scripture, section, chapter/verse, original text, romanization, translation,
  translator, edition, source URL, license, language, ingestion date and verification status
  (enforced by `scripture-pipeline/sanatana_pipeline/provenance.py`).
- If something cannot be legally included or verified, the site shows "source unavailable".

Known limitations:

- These are 19th/early-20th-century translations: archaic English, and some period interpretive
  choices. Modern translations are better but are copyrighted.
- IAST transliteration is machine-generated.
- OCR cleaning can leave small errors; report one and it can be fixed in the importer's correction table.
