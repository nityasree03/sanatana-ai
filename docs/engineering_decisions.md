# Engineering decisions

| Date       | Decision                                                                                                                                                 | Why                                                                                                                                     |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10-27 | Next.js 16 (App Router) + TypeScript + Tailwind CSS v4                                                                                                   | Required stack; one codebase for pages and server routes                                                                                |
| 2026-10-27 | `src/` folder layout with `@/*` import alias                                                                                                             | Keeps app code separate from config files                                                                                               |
| 2026-10-27 | System font stack instead of Google Fonts                                                                                                                | Build environment could not reach Google Fonts; self-hosting is also more private. Self-hosted fonts come in Phase 1                    |
| 2026-10-27 | Vitest + Testing Library for unit tests; Playwright (desktop + mobile) for browser tests                                                                 | Fast unit feedback plus real-browser checks                                                                                             |
| 2026-10-27 | `@types/node` 22 to match Node 22                                                                                                                        | Fixes a dependency conflict with Vitest                                                                                                 |
| 2026-10-27 | Provenance checklist written first in the Python pipeline                                                                                                | No passage may enter the site without source and license information                                                                    |
| 2026-10-27 | Central route registry drives menus, footer, home page and tests                                                                                         | Pages can never silently go missing from navigation or tests                                                                            |
| 2026-10-27 | Self-hosted fonts via @fontsource (Noto Sans, Noto Serif Devanagari, Cormorant Garamond; all OFL)                                                        | Devanagari support, no requests to Google, free licence                                                                                 |
| 2026-10-27 | Theme stored on `<html data-theme>` and applied by an inline script before paint; `useSyncExternalStore` keeps the toggle in sync                        | No colour flash, follows Next.js guidance, satisfies React lint rules                                                                   |
| 2026-10-27 | Per-companion accent colours via `data-companion` CSS variables, contrast-checked to WCAG AA (Krishna's blue darkened to #1a6b7b)                        | One component set, four looks, readable text                                                                                            |
| 2026-10-27 | Chat reads `?companion=` inside a Suspense boundary                                                                                                      | Required by Next.js 16 for URL data on prerendered pages                                                                                |
| 2026-10-27 | Automated accessibility scans (axe-core) in Playwright for every route                                                                                   | Catches problems early; found and fixed a list-semantics bug in the chat log                                                            |
| 2026-10-27 | Avatars: original SVG art only. Third-party reference images shared for style are not used or traced                                                     | Blueprint requires original or licensed assets                                                                                          |
| 2026-10-27 | Portraits as layered SVG with one shared face rig; states driven by CSS on `data-avatar-state`                                                           | Small, sharp at any size, no image files, easy to swap or restyle later                                                                 |
| 2026-10-27 | Approximate mouth loop while speaking, labelled as approximate                                                                                           | Browsers don't expose audio amplitude or phonemes for built-in voices; no false lip-sync claims                                         |
| 2026-10-27 | Speech behind `SpeechInputAdapter` / `SpeechOutputAdapter` interfaces with Web Speech API implementations                                                | Free, no keys; can be swapped for another engine later; tests use fakes                                                                 |
| 2026-10-27 | Spoken replies never autoplay; "Speak replies" is off by default                                                                                         | Blueprint requirement; respects users and browser autoplay rules                                                                        |
| 2026-10-27 | Voice privacy disclosed on the About page (browser vendors may process speech)                                                                           | Honest about where voice data goes; typing is always available                                                                          |
| 2026-10-27 | Owner-generated illustrated portraits (ChatGPT) replace the SVG portraits by default; animation by stacking six expression images and switching with CSS | Owner preferred the illustrated chibi style; image swapping gives blinking, talking and state changes without a heavy animation library |
| 2026-10-27 | Expression frames aligned automatically (OpenCV SIFT + RANSAC similarity transform) for blink/speak/concerned; listening/thinking crossfade unaligned    | Prevents the character jumping when frames switch; avoids rotating backgrounds for deliberately tilted poses                            |
| 2026-10-27 | `next/image` with `unoptimized` for portraits (pre-optimized WebP, ~35 KB each)                                                                          | No image-optimization quota needed on hosting; files already small                                                                      |
| 2026-10-27 | Scripture sources limited to public-domain translations (Besant, Griffith, Paramananda, Müller, Vijnanananda) plus Unlicense Sanskrit                    | Only texts we may legally republish; modern translations are copyrighted                                                                |
| 2026-10-27 | Wikisource `/wiki/` HTML and archive.org `/stream/` pages instead of their APIs/downloads                                                                | APIs were rate-limited or redirected to blocked hosts; HTML pages are stable and checksummed                                            |
| 2026-10-27 | Gita verse alignment uses both English verse numbers and Sanskrit `॥ N ॥` numbers                                                                        | Each source has missing or duplicated markers; two signals together give all 701 verses                                                 |
| 2026-10-27 | Every passage carries a verification label (clean source / checked against scan / cleaned from OCR)                                                      | Readers can see how much to trust each text                                                                                             |
| 2026-10-27 | Devi Gita taken from a 2018 clean transcription and compared with OCR of the 1921–23 scan (rapidfuzz ≥ 85)                                               | The scan's OCR alone was too noisy; the comparison proves the transcription matches the original                                        |
| 2026-10-27 | Scripture stored as versioned JSON in the repo, search in memory                                                                                         | Small dataset; no database, keys or cost                                                                                                |
| 2026-10-27 | Keyword search with BM25 + accent folding + small synonym list; meaning search with all-MiniLM-L6-v2 vectors; merged by reciprocal rank fusion           | Free, explainable, runs anywhere; fusion rewards passages found both ways                                                               |
| 2026-10-27 | Passage vectors made offline in Python (onnxruntime); query vectors in the browser (transformers.js), opt-in                                             | No model on the server and no paid API; download only for people who choose it                                                          |
| 2026-10-27 | ONNX Runtime engine copied from node_modules to `public/ort/` at build time (git-ignored)                                                                | transformers.js otherwise loads it from cdn.jsdelivr.net: an undisclosed third party. 27 MB file kept out of git                        |
| 2026-10-27 | Keyword search is the default; meaning search labelled experimental                                                                                      | Measured: keyword Hit@5 0.83 vs meaning 0.67 vs hybrid 0.79 on 24 labelled questions                                                    |
| 2026-10-27 | Unknown scripture URLs rejected in `src/proxy.ts`                                                                                                        | With Cache Components, `dynamicParams` is unavailable and a not-found inside the page streams with status 200                           |
| 2026-10-27 | Custom 404 page                                                                                                                                          | The default page did not match the site and offered no way back                                                                         |
| 2026-10-27 | Several translations of the same scripture are separate works (e.g. Gita by Besant, Telang, Arnold)                                                      | Readers can compare translators; each keeps its own provenance and numbering                                                            |
| 2026-10-27 | Sanskrit paired with an English section only when both have the same number of verses                                                                    | Numbering differs between editions (Kena 1 is off by one); a wrong pairing is worse than none                                           |
| 2026-10-27 | Numbered peace invocations on Wikisource pages are not counted as verses                                                                                 | They inflated verse counts (Katha 2.3 showed 19 verses instead of 18)                                                                   |
| 2026-10-27 | IAST candrabindu written as m̐ instead of the library's "~"                                                                                               | Standard IAST; fixed in three Gita verses too                                                                                           |
| 2026-10-27 | Long texts prerender their first 40 chapters; the rest render on first visit                                                                             | The full Ramayana has 653 sections; build stays at about 70 seconds; unknown chapters still 404 via proxy                               |
| 2026-10-27 | Hanuman Chalisa left out for now                                                                                                                         | No verifiable source for the original on reachable sites and no free English translation                                                |
| 2026-10-27 | Retrieval drop on everyday questions recorded, not tuned against the test set                                                                            | Tuning on the same 24 questions would overstate quality; Phase 4 will try principled fixes                                              |
| 2026-10-27 | Chat AI is Google Gemini on the free tier, behind one provider interface                                                                                 | Free, no card; the interface lets another provider be swapped in later                                                                  |
| 2026-10-27 | Gemini called with plain `fetch` (REST), not an SDK                                                                                                      | One small file, full control of timeout and errors, no extra dependency                                                                 |
| 2026-10-27 | The model must answer in a JSON schema; citations not among the supplied passage ids are dropped                                                         | Stops invented references reaching the page; "grounded" is computed, not trusted                                                        |
| 2026-10-27 | Scripture text in replies comes from our data, never from the model                                                                                      | The model may misquote; only verified text is shown as scripture                                                                        |
| 2026-10-27 | Self-harm messages get fixed crisis resources and are not sent to the AI                                                                                 | Safety must not depend on the model; resources checked (988, Tele-MANAS 14416)                                                          |
| 2026-10-27 | No key → scripture-only replies; `AI_PROVIDER=practice` stand-in for tests                                                                               | The site works and is honest without a key; tests don't depend on a live API                                                            |
| 2026-10-27 | Query vectors computed on the server with onnxruntime-web (WASM) and our own WordPiece tokenizer                                                         | Chat needs meaning search every time; native onnxruntime-node is too large for Vercel; transformers.js removed                          |
| 2026-10-27 | Model downloaded at build time from a pinned revision, checked by SHA-256                                                                                | Keeps 23 MB out of git while staying reproducible                                                                                       |
| 2026-10-27 | Passages re-embedded one at a time                                                                                                                       | Batch quantisation changed vectors; one-at-a-time matches query embedding                                                               |
| 2026-10-27 | Teaching texts preferred for personal questions; companion's own texts first, ≤2 per chapter                                                             | Measured gain on a held-out set (Hit@5 0.33 → 0.42); variety of sources                                                                 |
| 2026-10-27 | Per-IP limits: 12/min and 60/day for chat                                                                                                                | Protects the shared free quota                                                                                                          |
| 2026-10-28 | One `groundedAnswer()` for chat and Council; retry once only on unreadable replies                                                                       | One place for grounding checks; quota/outage retries already happen in the provider                                                     |
| 2026-10-28 | Truth Lens as a third field per citation (`reflection`), not a separate AI call                                                                          | No extra cost or latency; layers stay tied to the passage they come from                                                                |
| 2026-10-28 | Handoff: all messages ticked by default, but the dialog always appears after real exchanges                                                              | Sharing is an explicit, visible choice; unticking is one click                                                                          |
| 2026-10-28 | Council answers use only each companion's own texts                                                                                                      | Otherwise all four often cite the same Gita verse and the perspectives blur                                                             |
| 2026-10-28 | Council comparison is AI-written from the answers only, labelled, and never ranks them                                                                   | Blueprint asks for transparent synthesis; adding no new teachings keeps it checkable                                                    |
| 2026-10-28 | A Council question costs 5 against the rate limits                                                                                                       | It makes 5 AI calls; protects the shared free quota                                                                                     |
| 2026-10-28 | Living Leela scenes are hand-written data, not generated                                                                                                 | Choices must never change canonical events; tests verify passages and paths                                                             |
| 2026-10-28 | Header logo and theme button names include their visible text                                                                                            | WCAG 2.5.3 Label in Name, found by the Council page's full axe scan                                                                     |
