# Maintenance

| How often | Task                                                                          |
| --------- | ----------------------------------------------------------------------------- |
| Monthly   | Update dependencies (`npm outdated`), run all tests, check free-tier limits   |
| Quarterly | Review licenses of scripture, art and audio; review the AI provider and model |
| Yearly    | Upgrade major framework versions; re-run the full evaluation                  |

Keeping the site available for many years needs ongoing upkeep, and may eventually involve some cost.
